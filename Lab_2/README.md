# Лабораторная работа №2 — камера и освещение

Этот набор предназначен для добавления к существующему Vulkan starter-проекту.
`application.cpp` скопирован без изменений. Для рендеринга нужны четыре GLSL-шейдера,
а также заголовки интерфейсов приложения и графического слоя.

## Файлы

- `application.hpp` — объявления `application::initialize/update/render/shutdown`.
- `graphics_internal.hpp` — типы `Context`, `FrameData` и интерфейс графического слоя.
- `graphics_internal.cpp` — графический слой из предоставленного файла; исправлены обработка
  ошибок создания swapchain и сообщение после успешного `vkQueuePresentKHR`.
- `shaders/shader.vert` и `shaders/shader.frag` — геометрия и освещение Блинна—Фонга.
- `shaders/unlit.vert` и `shaders/unlit.frag` — постоянный цвет для фигур визуализации.
- `compile_shaders.sh` — компиляция GLSL в SPIR-V с помощью `glslc` или `glslangValidator`.

## Сборка шейдеров

Из этой директории выполните:

```bash
./compile_shaders.sh
```

Скрипт создаёт файлы `shaders/shader.vert.spv`, `shaders/shader.frag.spv`,
`shaders/unlit.vert.spv` и `shaders/unlit.frag.spv` — именно эти пути открывает
предоставленный `application.cpp`. Запускайте приложение из директории проекта,
чтобы относительный путь `shaders/...` был доступен.

Для Windows можно установить Vulkan SDK и запускать скрипт из совместимой оболочки
либо выполнить четыре эквивалентные команды `glslc` вручную. В существующем starter-проекте
сохраните исходные настройки сборки и подключение GLFW, Vulkan, GLM, ImGui, VkBootstrap
и Vulkan Memory Allocator.

## Управление

- `W/A/S/D` — перемещение камеры, `Q/E` — вниз/вверх.
- `Shift` — ускоренное перемещение.
- Зажатая правая кнопка мыши — поворот камеры.
- Позиция, yaw/pitch, FOV, ambient, материалы, направленный/точечные/прожекторные источники
  и визуализация источников меняются в интерфейсе ImGui.

Точечные и прожекторные источники хранятся в storage-буферах и представлены в GLSL
runtime-массивами без фиксированного размера в шейдере. Ёмкость CPU-буферов в текущем
`application.cpp` ограничена 64 источниками каждого типа.
